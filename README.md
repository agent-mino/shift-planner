# Work & Shift Planner

A single-page, offline-first planner for part-time shifts: weekly hour cap, class clashes, time away, pay by role and a simple budget.

All data is stored in the browser on the device (localStorage). Nothing is sent anywhere. Install on iPhone: open the site in Safari, Share, Add to Home Screen.

When changing app files, bump `VERSION` in `sw.js` so installed copies pick up the update.
